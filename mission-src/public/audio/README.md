Place your original tracks in each named room folder, then set paths in config.json, e.g. "bloop": "/audio/bloop/your-track.mp3". MP3, WAV, OGG, M4A work when supported by the browser. Tracks remain null until supplied. voices maps optional dialogue IDs to original narration paths. Music starts only after a player gesture, loops without restarting on each frame, and crossfades between rooms. Volume and mute also control interaction tones.
